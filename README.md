## UnrealRoboticsLab (URL)

The **Unreal Robotics Lab (URL)** is a **Unreal Engine Plugin** that provides a high-fidelity simulation environment for robotics research.

See Arxiv https://arxiv.org/abs/2504.14135 for the paper.

### Overview: What is URL?

The URL framework is designed to overcome the challenge of simultaneously achieving **photorealistic rendering** and **accurate physics modeling** in robotics simulation.

It achieves this by:

1.  **Leveraging Unreal Engine:** For advanced, photorealistic rendering and complex visual effects.
2.  **Integrating MuJoCo:** Utilizing MuJoCo's engine for high-precision, accurate physics simulation and rigid body dynamics.

This powerful combination enables researchers to conduct safe, efficient, and robust testing of perception, control, and navigation algorithms in controlled yet diverse scenarios.

---

### Key Features & Description

High-fidelity simulation is essential for robotics research, enabling safe and efficient testing of perception, control, and navigation algorithms. This framework presents a novel simulation environment that integrates the advanced rendering capabilities of the Unreal Engine with MuJoCo’s high-precision physics simulation.

Our approach enables **realistic robotic perception** while maintaining **accurate physical interactions**, facilitating benchmarking and dataset generation for vision-based robotics applications.

The system supports complex environmental effects, such as **smoke, fire, and water dynamics**, which are critical to evaluating robotic performance under adverse conditions. We benchmark visual navigation and SLAM methods within our framework, demonstrating its utility for testing real-world robustness in controlled yet diverse scenarios. By bridging the gap between physics accuracy and photorealistic rendering, our framework provides a powerful tool for advancing robotics research and sim-to-real transfer.
